# León de Judá - Frontend 🎨

The frontend of "Impresiones Gráficas León de Judá" is a modern, high-performance web application designed to showcase premium graphic services.

## ✨ Key Features

- **Responsive Design:** Optimized for mobile, tablet, and desktop.
- **Premium UI:** Sophisticated design with smooth animations using Framer Motion.
- **Performance:** Leveraging Next.js 15/16 App Router for fast loading and SEO.
- **Dynamic Icons:** Integrated with Lucide React for a clean visual language.

## 🛠 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **State Management:** React Context API (where applicable)

## 🚀 Getting Started

### Prerequisites
Make sure you have installed the dependencies in the root folder or run:
```bash
npm install
```

### Development Server
Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📁 Project Structure

- `app/`: Routing and main pages.
- `components/`: Reusable UI components (Buttons, Cards, Modals).
- `sections/`: High-level page sections (Hero, Services, Contact).
- `public/`: Static assets and images.

## 📝 Scripts

- `npm run dev`: Starts the development server.
- `npm run build`: Builds the application for production.
- `npm run start`: Starts the production server.
- `npm run lint`: Runs ESLint for code quality checks.
