# León de Judá - Web Experience 🦁

Professional web experience and management system for **"Impresiones Gráficas León de Judá"**. This project integrates a high-performance frontend with a robust backend to provide a seamless user experience.

## 🚀 Project Overview

This repository is organized as a monorepo containing:
- **Frontend:** A modern, premium landing page built with Next.js 15+ and Tailwind CSS 4.
- **Backend:** A scalable REST API built with Node.js, Express, and MongoDB.
- **Docs:** Comprehensive architecture and structure documentation.

## 🛠 Tech Stack

### Monorepo Simple
- **Frontend (frontend/):** Next.js 16 (App Router) + Tailwind CSS 4.
- **Backend (backend/):** Logic layer with Mongoose services and models.
- **Database:** MongoDB Atlas (Cloud).
- **Deployment:** Vercel (Integrated Serverless).

## 📦 Getting Started

### Prerequisites
- Node.js (Latest LTS recommended)
- MongoDB Atlas account or local instance

### Installation

1. Clone the repository.
2. Install dependencies for all components:
   ```bash
   npm install
   ```

### Development

To run both the frontend and backend concurrently:
```bash
npm run dev
```

The frontend will be available at `http://localhost:3000` and the backend at `http://localhost:5000` (default).

## 📂 Structure
- `/frontend`: Next.js application.
- `/backend`: Express API.
- `/docs`: Project documentation and architecture details.
